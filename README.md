# metaphor-illustration-skill

为文章、教程和社交帖创作静态配图的 agent skill。核心方法：不给题材画图标，而是给正文的论点找一个因果结构相同的生活隐喻，把它演成画面里正在发生的一件事。

## 底层心法

- 画观点，不画名词：每张图的起点是它要证明的那句判断。
- 隐喻要同构，不要相似：隐喻的因果结构与真实机制一致，没看过正文的人指着图能猜对这段讲什么。
- 画事件，不摆图标：一图一证，图里有主体、动作、结果和情绪；图里不许有字。
- 约束即风格：风格锁与配色定额开工前定死，逐张复用。
- 原图与提示词全文必须一起存档。
